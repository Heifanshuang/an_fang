# 告警历史功能实现文档

## 项目概述

本项目实现了一个完整的告警历史功能，包括前端展示和后端数据处理，主要用于监控和记录各种设备的告警信息，如温湿度异常、水浸异常、烟雾报警、非法闯入等。

## 前端实现

### 1. 告警历史页面布局

- **文件**：`app/src/main/res/layout/fragment_report.xml`
- **功能**：实现告警历史记录的表格展示，包含序号、时间、类型、关联设备等列
- **特点**：
  - 支持分页显示，每页最多10条记录
  - 包含自动刷新、手动刷新、暂停刷新等功能
  - 支持删除当前页记录
  - 响应式设计，适配不同屏幕尺寸

### 2. 告警历史Fragment

- **文件**：`app/src/main/java/com/example/myapplication/AlarmHistoryFragment.java`
- **功能**：实现告警历史记录的展示、筛选、搜索和详情查看功能
- **主要组件**：
  - TableLayout：用于展示告警历史记录
  - 分页控件：实现上一页、下一页、当前页显示
  - 刷新控件：实现自动刷新、手动刷新、暂停刷新
  - 删除控件：实现删除当前页记录
- **核心功能**：
  - 数据获取与更新
  - 分页显示
  - 自动刷新机制
  - 设备名称识别与转换
  - 告警类型转换

### 3. 导航菜单

- **文件**：`app/src/main/res/menu/nav_menu.xml`
- **功能**：在侧边导航菜单中添加告警历史选项
- **修改**：将"数据报表"修改为"机房环境数据报表"

### 4. 主活动

- **文件**：`app/src/main/java/com/example/myapplication/MainActivity.java`
- **功能**：处理导航菜单点击事件，切换到告警历史Fragment
- **修改**：将标题从"数据报表"修改为"机房环境数据报表"

## 后端实现

### 1. 告警历史数据管理器

- **文件**：`app/src/main/java/com/example/myapplication/AlarmHistoryManager.java`
- **功能**：管理告警历史数据，实现数据的存储、获取、删除等功能
- **特点**：
  - 单例模式，确保数据一致性
  - 支持数据持久化
  - 支持添加、删除、清空告警记录
  - 支持获取最新的告警记录
  - 支持注册告警添加监听器

### 2. 数据抓取与处理

- **文件**：`app/src/main/java/com/example/myapplication/AlarmHistoryFragment.java`
- **功能**：从服务器获取告警历史数据，并进行处理和转换
- **主要流程**：
  1. 获取项目ID
  2. 获取策略执行记录
  3. 过滤特定条件的记录
  4. 将策略执行记录转换为告警历史对象
  5. 保存到告警历史数据管理器

### 3. 设备名称识别

- **文件**：`app/src/main/java/com/example/myapplication/AlarmHistoryFragment.java`
- **功能**：根据告警消息和条件描述识别设备名称
- **主要方法**：
  - `updateDeviceNameFromAlarmMsg`：从告警消息中提取设备类型
  - `extractSpecificDeviceName`：从条件描述中提取具体设备名称
  - `getDeviceNameByAlarmType`：根据告警类型获取设备名称

### 4. 后台通知服务

- **文件**：
  - `app/src/main/java/com/example/myapplication/NotificationHelper.java`
  - `app/src/main/java/com/example/myapplication/NotificationWorker.java`
  - `app/src/main/java/com/example/myapplication/NotificationForegroundService.java`
- **功能**：实现后台数据抓取和通知功能
- **特点**：
  - 使用WorkManager调度后台任务
  - 支持前台服务保活
  - 适配Android 8.0+/12+/13+版本
  - 支持动态数据展示在通知弹窗

## 修复的问题

### 1. 关联设备显示问题

- **问题**：前三条告警记录的关联设备显示为空
- **原因**：设备名称获取逻辑错误，当告警类型不是"策略执行"时，返回空字符串
- **修复**：改进设备名称获取逻辑，优先使用设备原始名称，再尝试从告警消息中提取

### 2. 数据报表标题修改

- **问题**：数据报表标题不符合需求
- **修复**：将"数据报表"修改为"机房环境数据报表"

### 3. 后台服务兼容性问题

- **问题**：前台服务配置不兼容低版本Android系统
- **修复**：移除了前台服务的`android:foregroundServiceType`属性，使用兼容方式创建PeriodicWorkRequest

### 4. 特定条件记录过滤问题

- **问题**：特定条件的记录（如"{多合一温度}<=35 and {多合一湿度}<=50"）被错误地显示在告警历史中
- **修复**：添加了特定条件记录过滤逻辑，跳过这些记录

### 2. 设备名称提取

```java
// 从条件描述中提取具体设备名称
private String extractSpecificDeviceName(String conditionCn, String gatewayName) {
    if (conditionCn == null) {
        return gatewayName != null ? gatewayName : "未知设备";
    }
    
    // 转换为小写，提高匹配准确性
    String lowerCondition = conditionCn.toLowerCase();
    
    // 识别常见设备类型
    if (lowerCondition.contains("烟雾") || lowerCondition.contains("烟感")) {
        return gatewayName + (gatewayName.isEmpty() ? "" : " - ") + "烟雾报警器";
    } else if (lowerCondition.contains("多合一温度") || (lowerCondition.contains("温度") && lowerCondition.contains("湿度"))) {
        return gatewayName + (gatewayName.isEmpty() ? "" : " - ") + "多合一温湿度传感器";
    } else if (lowerCondition.contains("水浸") || lowerCondition.contains("漏水")) {
        return gatewayName + (gatewayName.isEmpty() ? "" : " - ") + "水浸传感器";
    } else if (lowerCondition.contains("门") || lowerCondition.contains("门禁") || lowerCondition.contains("非法闯入")) {
        return gatewayName + (gatewayName.isEmpty() ? "" : " - ") + "门禁传感器";
    } else {
        // 从条件中提取设备类型
        String deviceType = "未知设备";
        if (lowerCondition.contains("=") && !lowerCondition.contains("and")) {
            int eqIndex = lowerCondition.indexOf("=");
            if (eqIndex > 0) {
                String conditionPart = lowerCondition.substring(0, eqIndex).trim();
                if (conditionPart.startsWith("{") && conditionPart.endsWith("}")) {
                    conditionPart = conditionPart.substring(1, conditionPart.length() - 1);
                }
                deviceType = conditionPart + "传感器";
            }
        }
        return gatewayName + (gatewayName.isEmpty() ? "" : " - ") + deviceType;
    }
}
```
