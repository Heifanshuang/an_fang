# 告警历史功能实现方案

## 1. 功能需求分析

根据《机房设备环境简易预警系统页面设计.md》文档及新增需求，告警历史页面需要实现以下核心功能：

| 功能项 | 详细描述 |
| ------ | -------- |
| 告警列表 | 显示历史告警事件，包含时间、类型、级别、位置、处理状态 |
| 筛选功能 | 按时间范围、告警类型、告警级别筛选 |
| 搜索功能 | 按关键词搜索告警信息 |
| 告警详情 | 显示告警的详细信息和处理记录 |
| 分页功能 | 支持分页查看历史告警 |
| 告警处理 | 支持标记告警为已处理 |
| 导出功能 | 支持导出告警记录 |
| 灯光控制 | 基于环境参数自动控制灯光开关<br>- 紧急条件：温度≥35℃或湿度≥60%时，自动开启灯光<br>- 非紧急条件：温度<35℃且湿度<60%时，自动关闭灯光 |
| 数据上传 | 实时上传满足紧急条件的告警数据至告警历史界面，包含时间戳、温度值、湿度值、触发条件类型及紧急程度标识 |

## 5. 核心功能实现

### 5.1 灯光控制逻辑

```java
public class LightControlLogic {
    // 从配置中心获取阈值，默认值作为 fallback
    private double temperatureThreshold = 35.0;
    private double humidityThreshold = 60.0;
    
    // 配置更新方法，支持动态调整阈值
    public void updateThresholds(double tempThreshold, double humidityThreshold) {
        this.temperatureThreshold = tempThreshold;
        this.humidityThreshold = humidityThreshold;
    }
    
    // 灯光控制决策方法
    public boolean shouldTurnOnLight(double temperature, double humidity) {
        // 紧急条件：温度≥35℃或湿度≥60%时，自动开启灯光
        if (temperature >= temperatureThreshold || humidity >= humidityThreshold) {
            return true;
        }
        // 非紧急条件：温度<35℃且湿度<60%时，自动关闭灯光
        return false;
    }
    
    // 执行灯光控制
    public void controlLight(double temperature, double humidity, DeviceController deviceController) {
        boolean shouldTurnOn = shouldTurnOnLight(temperature, humidity);
        if (shouldTurnOn) {
            deviceController.turnOnLight();
        } else {
            deviceController.turnOffLight();
        }
    }
}
```

### 5.2 数据上传逻辑

```java
public class AlarmDataUploader {
    private AlarmHistoryService alarmHistoryService;
    private LightControlLogic lightControlLogic;
    
    // 数据上传方法
    public void uploadAlarmData(double temperature, double humidity, String deviceId) {
        // 检查是否满足紧急条件
        boolean isUrgent = lightControlLogic.shouldTurnOnLight(temperature, humidity);
        
        if (isUrgent) {
            // 构建告警数据
            AlarmHistory alarm = new AlarmHistory();
            alarm.setDeviceId(Long.parseLong(deviceId));
            alarm.setTemperature(temperature);
            alarm.setHumidity(humidity);
            alarm.setAlarmLevel(2); // 紧急告警
            alarm.setUrgencyFlag("紧急");
            
            // 确定触发条件类型
            if (temperature >= lightControlLogic.getTemperatureThreshold()) {
                alarm.setAlarmType("温度告警");
                alarm.setAlarmMsg("温度过高！");
                alarm.setTriggerCondition("temperature");
            } else {
                alarm.setAlarmType("湿度告警");
                alarm.setAlarmMsg("湿度过高！");
                alarm.setTriggerCondition("humidity");
            }
            
            // 设置时间戳和其他必要信息
            alarm.setStartTime(new SimpleDateFormat("yyyy-MM-dd HH:mm:ss").format(new Date()));
            alarm.setStatus(0); // 未处理
            
            // 上传数据到告警历史
            alarmHistoryService.saveAlarmHistory(alarm);
        }
    }
}
```

### 5.3 告警级别体系设计

| 告警级别 | 数值 | 描述 | 触发条件 | 处理方式 |
| -------- | ---- | ---- | -------- | -------- |
| 正常     | 0    | 设备状态正常 | 温度<35℃且湿度<60% | 无 |
| 警告     | 1    | 设备状态异常，需关注 | 温度30-35℃或湿度50-60% | 记录日志 |
| 紧急告警 | 2    | 设备状态严重异常 | 温度≥35℃或湿度≥60% | 记录日志+自动控制灯光+发送通知 |

## 10. 性能优化考虑

1. **数据库优化**：
   - 创建合适的索引，提高查询效率
   - 分页查询时使用limit offset或游标分页
   - 对于大数据量查询，考虑使用异步导出

2. **缓存优化**：
   - 缓存常用的筛选选项，如告警类型、位置等
   - 缓存热点告警数据
   - 缓存系统配置，减少数据库查询次数

3. **前端优化**：
   - 使用虚拟列表或无限滚动，优化大数据量列表的渲染性能
   - 实现筛选条件的记忆功能，提升用户体验
   - 使用防抖节流，优化搜索和筛选的性能

4. **系统稳定性**：
   - 实现API接口的限流和熔断机制
   - 增加日志记录，便于问题排查
   - 实现异常处理，确保系统稳定运行
