# 物联网云平台后端开发文档

## 1. 项目概述

本项目是一个物联网云平台的后端服务，基于Spring Boot框架开发，提供了完整的设备管理、传感器数据采集与分析、策略管理等功能。平台采用RESTful API设计，支持JWT认证，便于前端应用集成和扩展。

## 2. 技术栈

| 技术 | 版本 | 用途 |
| --- | --- | --- |
| Spring Boot | 3.2.2 | 后端框架 |
| Spring Data JPA | 3.2.2 | ORM框架 |
| Spring Security | 3.2.2 | 安全框架 |
| MySQL | 8.0+ | 数据库 |
| JWT | 0.12.3 | 认证机制 |
| Lombok | 1.18.30 | 简化代码 |
| Maven | 3.6+ | 项目构建 |
| Java | 11+ | 开发语言 |

## 6. API响应格式

所有API接口都采用统一的响应格式：

```json
{
  "ResultObj": {},        // 响应结果数据
  "Status": 0,            // 状态码：0-成功，1-失败
  "StatusCode": 1,        // 业务状态码
  "Msg": "成功",           // 响应消息
  "ErrorObj": {}          // 错误信息
}
```

### 6.1 分页响应格式

```json
{
  "ResultObj": {
    "PageSet": [],        // 分页数据列表
    "PageCount": 1,       // 总页数
    "PageIndex": 1,       // 当前页码
    "PageSize": 10,       // 每页条数
    "RecordCount": 100    // 总记录数
  },
  "Status": 0,
  "StatusCode": 1,
  "Msg": "成功",
  "ErrorObj": {}
}
```

## 7. JWT认证

### 7.1 认证流程

1. 用户通过登录接口获取JWT令牌
2. 客户端在后续请求的Authorization头中携带令牌：`Bearer {token}`
3. 服务器验证令牌的有效性
4. 验证通过后，允许访问受保护资源

### 7.2 JWT配置

在`application.properties`中配置JWT相关参数：

```properties
# JWT配置
jwt.secret=iot_platform_secret_key_2024
jwt.expiration=3600000
jwt.refresh-expiration=86400000
```

## 9. 使用说明

### 9.1 环境准备

1. 安装JDK 11+和Maven 3.6+
2. 安装MySQL 8.0+数据库
3. 创建名为`iot_platform`的数据库

### 9.2 配置修改

修改`application.properties`中的数据库连接信息：

```properties
# Database Configuration
spring.datasource.url=jdbc:mysql://localhost:3306/iot_platform?useUnicode=true&characterEncoding=utf8&useSSL=false&serverTimezone=Asia/Shanghai
spring.datasource.username=root
spring.datasource.password=123456
```

### 9.3 项目启动

在项目根目录下执行以下命令：

```bash
mvn spring-boot:run
```

项目将在`http://localhost:8080`上运行。

### 9.4 接口测试

使用API测试工具（如Postman、Insomnia等）测试接口，步骤如下：

1. 调用登录接口获取JWT令牌
2. 在请求头中添加`Authorization: Bearer {token}`
3. 调用其他需要认证的接口

## 10. 注意事项

1. 确保数据库连接信息正确配置
2. JWT令牌有效期为1小时，过期后需要重新登录获取
3. 所有接口都返回统一的响应格式，便于前端处理
4. 项目采用了CORS配置，允许跨域请求
5. 生产环境中建议修改JWT密钥为更复杂的字符串
6. 生产环境中建议关闭`spring.jpa.hibernate.ddl-auto=update`配置，使用数据库迁移工具（如Flyway）管理表结构
