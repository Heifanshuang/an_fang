# 设备控制文档

## 1. 系统概述

### 1.1 系统功能简介

物联网云平台是一个用于管理和控制物联网设备的系统，主要功能包括：

- 设备管理：设备的添加、更新、删除和查询
- 设备控制：向设备发送命令和控制指令
- 传感器数据管理：上传、查询和分析传感器数据
- 告警管理：自动检测和处理设备告警
- 用户认证：提供安全的用户登录和API访问机制
- 系统配置：灵活的系统参数配置

## 5. 告警管理

### 5.1 告警级别配置

系统根据不同的告警类型和严重程度，将告警分为三个级别：

- **正常**：设备运行正常，无异常情况
- **严重**：设备出现异常，但尚未影响正常运行
- **紧急**：设备出现严重异常，需要立即处理

具体告警级别配置如下：

| 告警类型 | 正常范围 | 严重范围 | 紧急范围 |
|---------|---------|---------|---------|
| 温度    | 0-35℃   | 35-40℃  | >40℃    |
| 湿度    | 0-60%   | 60-70%  | >70%    |
| 漏水    | -       | -       | 紧急    |
| 烟雾    | -       | -       | 紧急    |
| 闯入    | -       | 严重    | -       |

### 5.2 告警自动检测

系统会自动根据传感器数据和告警配置检测告警情况：

1. 当设备上传传感器数据时，系统会自动检查数据是否超出阈值
2. 如果超出阈值，系统会创建相应的告警记录
3. 告警记录包含设备ID、告警类型、告警级别、告警信息和告警时间
4. 系统会避免短时间内重复创建相同类型的告警（1分钟内）

### 6.4 认证方式

系统支持两种认证方式：

1. **Bearer Token**：使用JWT令牌进行认证，令牌需放在Authorization头中，格式为`Bearer <AccessToken>`
2. **ApiKey**：直接使用APIKey进行认证，APIKey需放在Authorization头中

## 7. 系统配置

### 7.1 数据库配置

数据库配置信息存储在`config.py`文件中，包括：

```python
DB_CONFIG = {
    "host": "localhost",          # MySQL主机
    "port": 3306,                 # MySQL端口
    "user": "root",               # MySQL用户名
    "password": "123456",         # MySQL密码
    "database": "room_alarm_cloud"# 数据库名
}
```

### 7.2 告警配置

告警配置信息存储在`config.py`文件中，包括：

```python
ALARM_LEVEL = {
    "temp": {
        "normal": (0, 35),        # 正常：0-35℃
        "serious": (35, 40),      # 严重：35-40℃
        "emergency": (40, 100)    # 紧急：>40℃
    },
    "humidity": {
        "normal": (0, 60),        # 正常：0-60%
        "serious": (60, 70),      # 严重：60-70%
        "emergency": (70, 100)    # 紧急：>70%
    },
    "water": "emergency",         # 漏水直接算紧急
    "smoke": "emergency",         # 烟雾直接算紧急
    "intrusion": "serious"        # 闯入算严重
}
```

### 7.3 通知配置

通知配置信息存储在`config.py`文件中，包括：

```python
NOTIFY_CONFIG = {
    "email_enable": False,        # 邮件通知开关
    "wechat_enable": False        # 企业微信通知开关
}
```

## 8. 系统部署和运行

### 8.1 依赖安装

1. 安装Python 3.8或更高版本
2. 安装依赖库：
   ```bash
   pip install fastapi pymysql pydantic python-jose
   ```

### 8.2 数据库初始化

1. 创建MySQL数据库：`room_alarm_cloud`
2. 创建必要的数据表（系统会自动创建或需要手动创建）

### 8.3 启动服务

1. 运行主程序：
   ```bash
   python main.py
   ```
2. 服务将在`http://127.0.0.1:8000`上运行
3. 访问`http://127.0.0.1:8000/docs`可查看API文档

## 9. 开发和扩展

### 9.1 API扩展

系统使用FastAPI框架，扩展API非常方便：

1. 在main.py文件中添加新的路由装饰器
2. 实现对应的处理函数
3. 添加必要的请求参数验证和响应处理

### 9.2 功能扩展

系统设计具有良好的扩展性，可以方便地添加新功能：

- 可以添加新的传感器类型
- 可以扩展告警通知方式（邮件、短信、微信等）

- 可以扩展设备协议支持

## 10. 常见问题和解决方案

### 10.1 设备无法连接

- 检查设备ID和安全密钥是否正确
- 检查网络连接是否正常
- 检查设备是否已添加到系统中

### 10.2 数据上传失败

- 检查请求格式是否正确
- 检查设备ID是否存在
- 检查数据类型是否符合要求

### 10.3 告警未触发

- 检查告警配置是否正确
- 检查传感器数据是否超出阈值
- 检查设备是否正常上传数据

### 10.4 认证失败

- 检查AccessToken是否有效
- 检查APIKey是否正确
- 检查认证头格式是否正确
